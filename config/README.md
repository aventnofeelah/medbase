# Medbase

## Цифровая медицинская платформа для хранения медицинской истории и записей в одном месте.

## Установка

> Клонирование репозитория

```
git clone https://github.com/aventnofeelah/medbase 
cd medbase
```

> Создание виртуального окружения

`python -m venv venv`

Windows\
`venv\Scripts\activate`

Linux/MacOS\
`source venv/bin/activate`

> Установка зависимостей

`pip install -r requirements.txt`

> Настройка переменных окружения

Создайте файл `.env`

Сгенерировать новый `SECRET_KEY` можно с помощью команды `python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"` в терминале

```
SECRET_KEY=
DEBUG=True

ADMIN_URL=admin/
```

если вы используете базу `PostgreSQL`, то добавьте 

```
DB_NAME=your-db-name
DB_USER=your-username
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432
```

или `SQLite`

```
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

> Выполнение миграций

`python manage.py migrate`

> Создание суперпользователя 

`python manage.py createsuperuser`

## Использование

### Добавление пользователей и медцентра

> Запуск проекта 

`py manage.py runserver`

Для использования ассинхронных задач, откройте второй терминал и выполните `py manage.py run_huey`

> Добавление медцентра 

После создание суперпользователя в админ панели создайте медцентр

![Добавление медцентра](screenshots-md/create-medcenter.png)

> Добавление врача

Добавьте врача я привяжите его к вашему медицинскому центру

![Добавление врача](screenshots-md/create-doc.png)

> Добавление пользователя/пациента

Создайте пользователя

![Добавление пользователя](screenshots-md/create-user.png)

> Добавление данных пользователя/пациента

В админ панели перейдите на вкладку **Пользователи(данные)** и выберите пользователя, которого вы добавили. Заполните данные на ваше усмотрение

![Добавление данных пользователя](screenshots-md/create-user-data.png)

### Пример добавления медицинских записей

* После запуска проекта, он будет доступен по адресу `http://127.0.0.1:8000/`
* На главной странице войдите под данными врача, которого вы добавили. После в поле поиска введите ИИН пользователя, которого вы добавили.
* Выберите тип медицинской записи для добавления (болезнь, операция, препараты и тд.), заполните данные и нажмите добавить.
* После, зайдите в учентую запись пользователя, которого вы добавили, откройте вкладку **Коды подтверждения**, выберите тип медицинской записи, которую вы добавили и скопируйте код
* Обратно войдите в учетную запись врача и вернитесь на страницу подтверждения кода от пользователя. Введите код и запись будет добавлена.
* На главной странице вы можете посмотреть историю ваших действий
